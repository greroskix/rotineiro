## 📋 Sobre o Projeto

O **Rotineiro** nasceu da necessidade real de organizar e monitorar a rotina de uma idosa com Alzheimer. A aplicação funciona como um painel de controle diário, onde o cuidador pode:

- ✅ **Marcar tarefas** da rotina conforme forem concluídas ao longo do dia
- 💊 **Confirmar medicamentos** em cada momento (manhã, tarde e noite)
- 💧 **Acompanhar a hidratação** com contador de copos de água
- 📊 **Visualizar o progresso** geral do dia em tempo real
- ⏰ **Identificar a atividade atual** com base no horário automaticamente
- 👤 **Criar uma conta** para salvar o histórico e não perder o progresso

## 💡 Funcionalidades

| Funcionalidade | Descrição |
|:--- |:--- |
| **📅 Rotina por Período** | Tarefas divididas em Manhã, Tarde e Noite com horários definidos |
| **💊 Controle de Remédios** | 9 momentos de medicação ao longo do dia com checkbox de confirmação |
| **💧 Hidratação** | Contador visual de copos de água com meta diária |
| **⏰ Atividade Atual** | Banner automático exibindo a tarefa do momento com base no horário |
| **📊 Progresso** | Barra de progresso geral e percentual atualizado em tempo real |
| **👤 Sistema de Contas** | Login com e-mail e senha para salvar histórico entre sessões |
| **🔄 Reiniciar Dia** | Reset completo da rotina para recomeçar o acompanhamento |
